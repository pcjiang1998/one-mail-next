# Outlook Icon

`outlook-icon.ico` is the Outlook web application's favicon, bundled locally
to identify Outlook accounts without a runtime request to a favicon service.

Source: https://res.public.onecdn.static.microsoft/owamail/20241011003.19/resources/images/favicons/mail-seen.ico

Retrieved: 2026-10-24. The Outlook logo is a Microsoft brand asset.
