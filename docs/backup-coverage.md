# 备份范围

设置中的“是否备份邮件”默认勾选，同时控制本地 SQL 导出和 WebDAV / S3 上传。

| 数据                                              | 勾选   | 不勾选 |
| ------------------------------------------------- | ------ | ------ |
| 邮箱账号、密码和 OAuth 凭据                       | 保留   | 保留   |
| 联系人、邮箱地址、备注、星标                      | 保留   | 保留   |
| 全局和账号隐私策略、可信发件人                    | 保留   | 保留   |
| 各邮箱通知开关、新邮箱通知默认值                  | 保留   | 保留   |
| 文件夹选择、排序、同步开关                        | 保留   | 保留   |
| 全局和账号代理、签名、同步方式                    | 保留   | 保留   |
| 全局翻译服务、目标语言、服务密钥                  | 保留   | 保留   |
| 邮件规则及远端备份配置                            | 保留   | 保留   |
| 语言、主题、更新频率等软件设置                    | 保留   | 保留   |
| 已缓存邮件、正文、搜索索引、附件元数据            | 保留   | 不保留 |
| 草稿、发件箱、待办及提醒                          | 保留   | 不保留 |
| 同步进度、POP3 已收取记录、规则执行和远端写回记录 | 保留   | 不保留 |
| 磁盘上的附件文件                                  | 不包含 | 不包含 |

导入会替换当前数据库，不会合并数据。“不备份邮件”保留文件夹配置，但清除邮件计数、同步游标和账号上次同步时间。恢复后按原同步设置重新拉取；禁用同步或手动同步的账号需要用户自行启动同步。导出不会删除或修改源数据库中的邮件。

数据库内的密码、OAuth 凭据、翻译密钥和远端备份密钥随数据库一起迁移。SQL 文件头和文件名包含数据库解密所需信息，因此本地 SQL 备份应视为敏感文件；远端上传沿用读取密钥加密。

开机启动设置保存在数据库中，导入后会重新应用到当前系统；是否受支持仍由平台决定。系统默认邮件客户端注册、窗口位置和磁盘文件不属于数据库备份范围。

测试使用独立临时数据库，覆盖含邮件和仅设置两种恢复方式、外键完整性、凭据解密、文件夹同步进度重置，以及 WebDAV / S3 上传对备份选项的传递。通知页测试覆盖单账号修改、全部开启/关闭、失败提示和无账号状态。
