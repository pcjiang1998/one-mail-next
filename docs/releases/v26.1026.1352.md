# OneMail Next v26.1026.1352

发布日期：2026-10-26。应用版本：`26.1026.1352`。发布标签：`v26.1026.1352`。升级基线：`v26.1024.1715`。

本版是针对七项现有问题的修复版本，不包含新的账号认证方案，也不改变远程内容隐私策略。

## 中文

### 更新补丁说明

1. **跨页面侧边栏宽度一致。** 邮箱、全部账号、具体文件夹、本地草稿箱和发送队列共用外层“账号栏 + 内容区”布局；收件列表与正文在内容区内部独立分栏。切换页面不再加载不同的账号栏宽度，窄窗口下同步调整内部最小尺寸约束。
2. **添加账号下拉列表正常滚动。** 服务商列表改用贴近输入框的定位方式，并按可用空间限制弹层高度，修复滚轮输入被抵消、列表跳位的问题。独立窗口默认尺寸为 520 × 680，最小 440 × 460，允许调整大小。
3. **不再保存空白草稿。** 主题和正文均无实际内容时，关闭或保存不会生成草稿；空格、换行、空段落、换行标签和不换行空格均视为空白。仅填写收件人不构成有效草稿，附件和内嵌图片仍会保留；已有草稿被清空后会删除。
4. **远端原位置不存在时保留本地可用性。** 确认原文件夹中的原 UID 已不存在后，本地副本继续可见，允许本地已读或未读更新，不再反复连接不存在的目标。已缓存正文、原始邮件和已下载附件继续可用；未缓存正文、附件或原始邮件会明确说明无法获取，转发不再生成空的原始邮件附件。
5. **批量操作不再推动邮件列表。** 工具栏固定在邮件列表面板底部、滚动区域之外，始终预留 48px。未选择时显示零项并禁用批量命令；首次选择、清空选择及滚动到底部后选择均不改变列表可视高度。
6. **修正翻译按钮层级。** 邮箱工作区使用独立堆叠上下文，写信、设置及对话框或抽屉位于翻译按钮上方，避免按钮穿透覆盖其他界面。
7. **补充 POP 原件保留提醒。** 添加账号选择 POP 协议时，提示服务器可能采用下载后删除策略、本地副本可能无法再次获取，并提醒到邮件服务商设置中保留服务器原始邮件；提供中英文提示。

### 远端缺失处理与数据一致性

- 将“远端原位置不存在”与本地隐藏或删除分开记录，不再通过隐藏本地邮件来表示远端缺失。文件夹计数包含仍可见的本地副本；远端缺失记录不再占用同步游标和近期标志刷新名额。
- 缺失判定保留 UIDVALIDITY 与 Message-ID 身份核验。网络超时、认证失败、UIDVALIDITY 变化及身份不匹配不会被当作远端缺失；本版不凭主题、发件人等相似信息自动绑定其他文件夹中的邮件。
- 确认缺失后，将相关远端标志写回结束为取消状态，避免反复失败重试；回复后的远端已回复标记也跳过已确认缺失的目标。同步中的取消通知在数据库事务成功提交后发出。
- 为本地已读更新增加原子递增的修订号，阻止延迟返回的旧重试覆盖较新的单封或批量本地状态。正文加载和预取同样保留当前已读及缺失状态，不以旧响应覆盖新状态。

### 版本与升级说明

- 本版可从 `v26.1024.1715` 升级。首次启动自动增加 `remote_missing` 和 `read_state_revision` 字段，恢复此前被全量同步隐藏的本地副本、修正计数，并取消已失效的远端标志写回；用户主动删除的记录保持删除状态。
- 建议升级前备份本地数据库及重要附件。SQL 备份不包含磁盘附件文件，备份中的敏感凭据材料应妥善保管。详见[备份范围](https://github.com/pcjiang1998/one-mail-next/blob/v26.1026.1352/docs/backup-coverage.md)。
- 远端缺失仅表示原位置不可获取，不代表邮件一定被永久删除。同步不能恢复从未缓存且服务器已无法提供的内容；本版不承诺找回这些正文或附件。
- 数据迁移后的旧版本回退未做验证。需要回退时，应保留升级前备份，不应假定旧版能完整理解新增的缺失状态。
- 发布工作流按所选标签检出代码，核对标签与应用版本，并将本文件作为 GitHub Release 正文。手动重新运行时也使用所选标签的代码。

### 验证与发布范围

- 本地完整回归通过：58 个测试文件、271 个用例，包含远端缺失处理以及已读更新与旧重试的并发回归。
- Node/Web 类型检查、生产构建、暂存区差异空白检查通过；暂存区 TS/TSX 文件没有 ESLint 错误。
- 浏览器交互验证覆盖两种主窗口宽度下的侧边栏一致性、两种账号窗口尺寸下的下拉框滚动、选择工具栏稳定性、设置及写信层级、空白草稿和 POP 提示。测试使用隔离数据，未连接真实用户邮箱或修改用户数据库。
- 全仓库仍有 7 个既有 ESLint 错误及格式警告，未宣称全仓库 lint 通过。尚未进行真实 IMAP 服务器延迟交错验证，以及各平台安装包安装后的人工验收。

### 仍然存在的限制

- Gmail / Outlook 重连及 OAuth 刷新问题未在本版修复。
- 账号代理仍未统一覆盖允许加载的远程图片、背景、跟踪资源及 OAuth 请求；现有隐私拦截策略不变。
- 当前 IMAP 会话尚未提供 UID 定向永久删除能力，因此该操作仍会被拒绝；恢复和规则移动仍要求服务器支持 `MOVE`。
- 部分已有界面的英文覆盖仍不完整。上一版本的其他兼容性与备份限制继续适用。

## English

Release date: October 26, 2026. Application version: `26.1026.1352`. Tag: `v26.1026.1352`. Upgrade baseline: `v26.1024.1715`.

### Patch Notes

1. **Consistent sidebar sizing.** Mail, All Accounts, folders, local drafts, and outbox share a stable outer account-sidebar/content layout. The mail list and reader resize inside the content area, with responsive minimum sizes for narrower windows.
2. **Stable provider-menu scrolling.** The add-account provider selector uses anchored positioning and an available-space height limit, fixing canceled scroll input and menu jumps. The window defaults to 520 × 680, has a 440 × 460 minimum, and is resizable.
3. **No whitespace-only drafts.** Closing or saving skips drafts with no meaningful subject or body, including spaces, line breaks, empty paragraphs, break tags, and nonbreaking spaces. Recipients alone do not count; attachments and inline images do. Clearing an existing draft removes it.
4. **Usable local copies after remote disappearance.** Confirmed absence of the original folder/UID keeps the local copy visible and permits local read/unread updates. Cached bodies, raw messages, and downloaded attachments remain usable. Uncached content is explicitly unavailable, and forwarding does not create an empty original-message attachment.
5. **No selection-induced list jumps.** Bulk actions stay outside the scroll area in a reserved 48px footer. The zero-selection state disables commands without removing the toolbar or changing the visible list height.
6. **Correct translation layering.** An isolated mailbox stacking context keeps the translation button below settings, the composer, dialogs, and drawers.
7. **POP retention warning.** Selecting POP explains that download-and-delete policies may make the local copy impossible to fetch again and directs users to retain original messages in their provider settings. Chinese and English warnings are included.

### Remote State and Consistency

- Remote absence is separate from deliberate local hiding/deletion. Visible local-only copies count toward folder totals and do not consume remote sync cursors or recent-flag refresh slots.
- UIDVALIDITY and Message-ID checks remain in place. Network/authentication errors, UIDVALIDITY changes, and identity mismatches are not treated as confirmed absence. Messages are not automatically reassociated across folders using subject/sender similarity.
- Confirmed missing targets cancel obsolete flag writebacks and skip answered-flag updates instead of retrying indefinitely. Synchronization broadcasts cancellations only after its database transaction commits.
- Atomic read-state revisions prevent delayed retries from overwriting newer single or bulk local changes. Body loads and prefetch responses also preserve newer read/missing state.

### Version and Upgrade Notes

- First launch adds `remote_missing` and `read_state_revision`, recovers copies hidden by earlier full synchronization, repairs counts, and cancels obsolete flag writebacks without undoing deliberate local deletions.
- Back up the database and important attachment files before upgrading. SQL backups do not contain attachment files on disk and include sensitive credential material. See [backup coverage](https://github.com/pcjiang1998/one-mail-next/blob/v26.1026.1352/docs/backup-coverage.md).
- A missing original location does not prove permanent deletion. Never-cached bodies or attachments cannot be recovered if the server no longer provides them.
- Downgrading after migration has not been verified. Retain a pre-upgrade backup rather than assuming older versions understand the new state.
- Release builds check out the selected tag, validate it against the application version, and publish these standalone notes, including manual reruns.

### Verification and Availability

- Passed 271 local tests in 58 files, including remote-missing handling and stale-retry/read-state concurrency regressions.
- Passed Node/Web type checks, production build, staged whitespace checks, and error-level ESLint for staged TS/TSX files.
- Isolated browser checks covered two main-window widths, two account-window sizes, menu scrolling, stable selection layout, settings/composer layering, blank drafts, and the POP warning. No real mailbox or user database was used.
- Seven pre-existing repository ESLint errors and formatting warnings remain. Live IMAP delayed-interleaving validation and installed-package smoke tests on every platform have not been completed.
- Cloud builds target Windows x64/ARM64 installers, macOS x64/ARM64 DMG/ZIP, and Linux x64/ARM64 AppImage/DEB. Availability depends on this tag's workflow results and attached assets.

### Known Limitations

- Gmail/Outlook reconnection and OAuth refresh are not fixed in this patch.
- Account-proxy coverage remains incomplete for allowed remote images, backgrounds, tracking resources, and OAuth requests; privacy blocking is unchanged.
- UID-scoped IMAP permanent deletion remains unavailable and rejected. Restore/rule moves still require server `MOVE` support.
- Some existing UI strings remain Chinese-only. Other compatibility and backup limitations from the previous release still apply.
