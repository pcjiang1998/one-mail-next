# OneMail Next v26.1024.1715

发布日期：2026-10-24。本文覆盖上一个正式版 `v26.730.1039`（`3cc3867`）至本版 `v26.1024.1715`（`807c049`）之间的全部功能更新、重要行为变化及已知限制，包含 10 月 23 日与 10 月 24 日的改动。

## 中文

### 联系人与分组

- 新增独立联系人页面，支持多个邮箱地址、默认地址、备注、星标、搜索和 vCard 导入导出；写信时提供联系人地址建议。
- 邮件发件人、收件人的悬浮信息卡新增“添加到联系人”，无需离开邮件即可保存联系人。
- 新增分组管理，同一联系人可以属于多个组；搜索可同时按关键词和分组筛选，写信时可按联系人组添加收件人。
- 列表支持复选框、全选筛选结果和批量删除确认。删除当前编辑的联系人会提示，删除其他联系人保留当前未保存的编辑内容；后端批量删除在同一事务中执行。

### 邮件看板与提醒

- 新增邮件任务看板，可从邮件创建事项，管理标题、备注、状态和提醒时间。
- 支持多选事项后批量拖拽到其他分栏，右键编辑事项信息及提醒时间。
- 看板提醒与全局、账号的新邮件通知设置独立，关闭新邮件通知不会关闭看板提醒。
- 修复联系人、看板独立窗口的拖动区域，将导入、导出、刷新等工具按钮与原生最小化、最大化、关闭按钮分开。

### 草稿箱、发送队列与侧边栏

- 本地草稿箱统一汇总各账号草稿，保留每封草稿的发件账号；支持搜索、账号筛选、每页 50 条分页和点击继续编辑。
- 修复打开本地草稿箱时反复刷新造成界面卡顿的问题。
- 草稿箱和发送队列改为主区域列表，不再使用抽屉；侧边栏顺序调整为“草稿箱”“发送队列”“全部邮箱”，之后为各账号。
- 草稿列表新增复选框、当前页全选和批量删除确认；切换页码、搜索或账号筛选会清空选择。
- 发送队列新增“清除已发送”“清除失败”，确认后清理全部对应状态的本地发送记录，不受当前加载条数限制。已发送记录虽然不显示在活动队列中，仍可清理。
- 清理发送记录不删除服务器邮件或草稿，也不影响排队和发送中的记录。

### 设置与新邮件通知

- 设置由弹窗改为占满应用窗口的页面，采用左侧导航、右侧内容，左上角可返回邮箱。
- 添加、编辑账号时可设置该账号的新邮件桌面通知；通知设置页支持逐个切换、全部开启和全部关闭，并立即保存。
- 常规设置新增新账号通知默认值。已有账号迁移后默认开启通知，新账号默认值初始为开启；修改默认值不追溯改变已有账号。
- 账号通知开关控制新邮件桌面弹窗和声音，不控制看板事项提醒。

### 远程内容隐私

- 将单一外部图片开关扩展为严格、宽松、不限制三种隐私模式，支持账号覆盖、可信邮箱地址及可信域名。
- “远程内容隐私”独立放在设置侧边栏，与“邮件规则”一起位于“网络”和“翻译”之间。
- 调整邮件 HTML 缓存与显示处理：远程资源以未激活形式保存，在展示时按当前策略处理图片、背景及其他远程资源；切换策略无需依赖此前按某一模式处理后的缓存。
- 宽松模式使用启发式跟踪识别，不能保证阻止所有跟踪资源。

### 邮件规则

- 新增规则管理与执行，支持按发件人、收件人、主题、正文及附件条件匹配，执行标为已读、加入看板、移入“已删除”等动作。
- 按规则顺序处理新增邮件并保存执行进度；首次同步、历史回填和 UIDVALIDITY 重置不批量触发历史邮件规则。

### 远端操作与发送状态

- 新增持久化远端写回记录及状态面板，展示账号、邮件摘要、操作、状态和错误；支持清除完成记录，保留排队和运行中的操作。
- 远端操作增加邮件身份核验和受限制的失败重试；重启应用或恢复数据库后不自动重放未完成命令。
- SMTP 接受邮件后，将后续本地记录更新、追加到已发送文件夹、已回复标记或审计记录失败作为警告处理，不再将这些失败混同为可重试的 SMTP 发送失败。
- 追加已发送邮件使用发送记录对应的写回标识，已记录成功时不重复追加。

### 备份与恢复

- 本地 SQL 导出及 WebDAV / S3 上传新增“是否备份邮件”，默认包含邮件；也可仅导出账号、联系人和设置。
- 两种模式均保留账号及凭据、联系人、隐私及可信发件人、通知、文件夹选择、代理、签名、同步偏好、邮件规则、翻译配置及密钥、远端备份配置等。大部分设置原本已随整库备份保存，本次新增的是可选范围及恢复验证。
- 仅设置备份排除邮件、正文、搜索索引、附件元数据、草稿、发件箱、待办提醒、同步进度及邮件操作记录；保留文件夹配置并重置邮件计数和同步游标。导出不会删除源数据库内容。
- 导入后重新应用开机启动及自动更新检查频率，并刷新同步服务。
- **恢复会替换当前本地数据库，不执行合并。** 仅设置恢复后需按同步设置重新拉取邮件，手动同步或禁用同步的账号需自行启动同步。
- **SQL 备份不包含磁盘附件文件。** 本地 SQL 含解密凭据所需的信息，应作为敏感文件保管；远端上传继续使用读取密钥加密。系统默认邮件客户端注册、窗口位置和磁盘文件不属于数据库备份范围。

### 图标、打包与验证

- Outlook、Hotmail 和 Microsoft 对应的 Outlook 标志使用内置 Microsoft 图标，修复远程图标加载失败导致的破图；其他服务商图标行为不变。
- 新增 PowerShell 7 Windows x64 目录版及安装包脚本，包含环境、版本检查和构建日志，支持跳过依赖安装。
- 打包范围收紧至 `out/main`、`out/preload`、`out/renderer`，避免测试用户数据进入安装包。
- 新增 `main` 推送和 PR 的 Windows / Linux CI，执行锁定依赖安装、测试、类型检查和生产构建；调整磁盘备份恢复测试的 Windows 等待时间。
- 功能提交已通过双平台 CI；本地验证通过 56 个测试文件、237 个用例、类型检查和生产构建，并完成草稿、队列、联系人、看板及 Outlook 图标的浏览器交互验证。现有部分 ESLint 报错尚未处理，不宣称全仓库 lint 通过。
- Release 工作流提供 Windows x64/ARM64 安装程序、macOS x64/ARM64 DMG 和 ZIP、Linux x64/ARM64 AppImage 和 DEB。各平台安装后的人工验收尚未完成。

### 兼容性与已知问题

- 远端永久删除现在要求 UID 定向删除；当前 `SimpleImapSession` 尚未提供 `uidExpunge`，因此 IMAP 永久删除会被拒绝。恢复与规则移动要求服务器支持 `MOVE`，不再使用复制后整箱清除的替代方式。
- Gmail / Outlook 重连和 OAuth 刷新问题只完成排查，尚未修复，也未确认此前 Outlook 异常的实际原因。Outlook 图标修复不等于连接问题解决。
- 账号代理尚未覆盖所有请求：新建 IMAP / POP3 / SMTP 连接及正文、附件读取沿用现有代理逻辑；允许加载的邮件远程图片、背景、跟踪资源和 OAuth 请求尚未统一走账号代理。现有隐私拦截策略未放宽。
- 联系人、看板、规则和写回等新增界面仍有固定中文文案，英文覆盖尚不完整。
- 邮件多选、文件夹视图、默认邮件客户端、POP3、翻译、基础代理和签名已存在于上个正式版，不重复计入本次新增功能。

## English

This is the cumulative update from `v26.730.1039` (`3cc3867`) to `v26.1024.1715` (`807c049`), including all changes from October 23 and 24, 2026.

### Contacts, board, and local workflows

- Added standalone contacts with multiple addresses, a default address, notes, stars, search, vCard import/export, and composer suggestions. Sender/recipient hover cards can create contacts directly.
- Added multiple groups per contact, combined text/group filtering, group recipients, and confirmed transactional bulk deletion. Unrelated unsaved contact edits are preserved.
- Added mail tasks with titles, notes, statuses, reminders, multi-item dragging, and context-menu editing. Task reminders are independent of global and account new-mail notifications.
- Fixed standalone Contacts/Board window dragging and overlap between toolbar actions and native window controls.
- Unified local drafts across accounts while retaining each sender, with search, account filters, 50-item pages, editing, page selection, and confirmed bulk deletion. Selection resets on filter/page changes; repeated refreshes causing freezes were fixed.
- Moved drafts and the sending queue into the main workspace, ordered before All Accounts in the sidebar. Clear Sent/Clear Failed acts on all matching local records, preserving server mail, drafts, queued items, and active sends.

### Settings, privacy, rules, and remote operations

- Replaced dialog settings with a full-window sidebar layout. Added per-account desktop mail notifications, individual/bulk switches, immediate saving, and a default for new accounts. Existing accounts migrate enabled; default changes do not alter existing accounts.
- Added strict, loose, and unrestricted remote-content policies, account overrides, and trusted addresses/domains. Privacy and Mail Rules are independent settings sections. Cached HTML keeps resource references inert until display-time policy processing; loose tracker detection remains heuristic.
- Added ordered rules matching sender, recipient, subject, body, and attachments, with mark-as-read, add-to-board, and move-to-Deleted actions. Initial synchronization, backfill, and UIDVALIDITY resets do not bulk-apply rules to historical mail.
- Added persistent remote-writeback records, status/error inspection, completion cleanup, identity checks, and restricted retries. Unfinished remote commands are not automatically replayed after restart or restore.
- After SMTP acceptance, subsequent bookkeeping, Sent-folder append, answered-flag, or audit errors become warnings rather than retryable SMTP failures. A successfully recorded Sent append is not repeated for the same outbox record.

### Backup, packaging, and verification

- Added optional mail inclusion to local SQL and WebDAV/S3 backups, enabled by default. Both modes preserve accounts/credentials, contacts, privacy, notifications, folder choices, proxies, signatures, synchronization preferences, rules, translation settings/keys, and remote-backup configuration.
- Settings-only backups omit mail/bodies/indexes/attachment metadata, drafts/outbox/tasks/reminders, sync progress, and operation history. Folder choices are retained while counters/cursors are reset; export does not modify source data. Restore reapplies startup/update preferences and refreshes sync services.
- Restore replaces the local database rather than merging. Settings-only restores require mail synchronization; manual/disabled accounts must be started explicitly. SQL backups exclude attachment files on disk and contain sensitive decryption material; remote uploads retain read-key encryption. OS default-mail registration, window position, and disk files are outside the database backup scope.
- Bundled the Outlook icon for Outlook-related providers. Added PowerShell 7 Windows x64 build scripts, environment/version checks and logs; narrowed packaged output to main/preload/renderer directories.
- Added Windows/Linux push/PR CI and adjusted Windows disk-restore test timing. The feature commit passed both CI platforms; local verification passed 237 tests in 56 files, type checks, production build, and browser interaction checks. Existing ESLint errors remain.
- Release packages target Windows, macOS, and Linux on x64/ARM64. Installed-package smoke tests have not been completed on every platform.

### Compatibility and known issues

- IMAP permanent deletion now requires UID-scoped expunge, which the current session implementation does not provide, so it is rejected. Restore/rule moves require server `MOVE` support rather than copy-and-unscoped-expunge.
- Gmail/Outlook reconnection and OAuth refresh were investigated, not fixed. The earlier Outlook error's cause remains unconfirmed; the icon fix is unrelated to authentication.
- Account-proxy coverage remains incomplete for allowed remote HTML images/backgrounds/tracking resources and OAuth requests. Existing mail transport/body/attachment proxy handling and privacy blocking remain unchanged.
- Some new UI strings are Chinese-only. Mail multi-selection, folder views, default-mail handling, POP3, translation, basic proxies, and signatures were already present in the previous release and are not counted as new features.
